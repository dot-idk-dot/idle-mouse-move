# Idle-Mouse‑Move
## О проекте
Скрипт PowerShell для Windows с автоматическим перемещением мыши, предотвращающий определение системой длительного простоя.
- ✅ Циклическое движение мыши: смещение влево на заданное количество пикселей, ожидание, возврат обратно и повтор цикла
- ✅ Встроенный настоящий API предотвращения сна системы, блокирует переход системы в спящий режим и автоматическое выключение монитора
- ✅ Работает полностью локально, подключение к интернету не требуется, управление курсором и питанием осуществляется через системные API Windows
- ✅ Две версии: релизная (без записи логов на диск), отладочная (вывод координат в лог для устранения неполадок)

> ⚠️ Важное примечание
> Оба скрипта используют логику относительного смещения, **не фиксируют базовую координату мыши, полученную при запуске скрипта**.
> При ручном перемещении мыши во время работы или при небольших системных колебаниях курсора положение мыши будет постепенно смещаться.

> ⚠️ Ограничения окружения
> Виртуальные машины и некоторые сеансы удаленного рабочего стола перехватывают API `SetCursorPos`, мышь не будет двигаться; программы безопасности могут блокировать вызовы скриптом системных интерфейсов Windows.
> На некоторых устройствах работает только перемещение мыши, предотвратить выключение дисплея невозможно.

## Список файлов
### `mouse_move.ps1` - **【Основной скрипт｜Релизная версия】**
- Назначение: повседневное использование, вывод только в консоль, **не записывает лог‑файлы на диск**
- Функции: циклическое перемещение мыши + включение защиты от сна системы (`SetThreadExecutionState`)
- Запускающий файл: `run_mouse_move.bat`

### `run_test.ps1` - **【Отладочный скрипт｜Для устранения неполадок】**
- Назначение: диагностика и отладка, создаёт файл `mouse_log.txt` в папке скрипта, записывает координаты мыши на каждой итерации цикла
- Функции: циклическое перемещение мыши + включение защиты от сна системы + запись логов на диск
- Внимание: постоянно записывает данные в лог на диск, **не подходит для длительной работы в фоне**
- Запускающий файл: `run_test.bat`

### `run_mouse_move.bat`
Релизный пакетный запускатель, двойной щелчок запускает основной скрипт `mouse_move.ps1`.
> Надпись `Keep screen awake` внутри бат‑файла соответствует реальному поведению: защита от сна активируется внутри скрипта PowerShell.
Способ остановки: нажать `Ctrl+C` в окне консоли или закрыть окно.

### `run_test.bat`
Отладочный пакетный запускатель, запускает тестовый скрипт, создаёт лог‑файл и включает защиту от сна.

### `mouse_log.txt`
> **Создаётся только при запуске `run_test.ps1`. Основной релизный скрипт этот файл не создаёт.**
> Содержит метку времени, номер цикла, координаты мыши до и после перемещения; запись ведётся в режиме добавления, старые логи не перезаписываются автоматически.

## Использование
### Способ 1: Запуск двойным щелчком (рекомендуется)
1. Повседневное использование: дважды щёлкните по `run_mouse_move.bat`
2. Требуются логи для отладки: дважды щёлкните по `run_test.bat`
3. Остановить скрипт: нажмите `Ctrl+C` или закройте окно консоли

### Способ 2: Ручной запуск через командную строку
```cmd
:: Запуск основного релизного скрипта
cd папка‑со‑скриптом
run_mouse_move.bat

:: Запуск отладочного скрипта
run_test.bat
```

### Способ 3: Прямой вызов скрипта PowerShell
```powershell
# Релизная версия
powershell -NoProfile -ExecutionPolicy Bypass -File mouse_move.ps1

# Отладочная версия
powershell -NoProfile -ExecutionPolicy Bypass -File run_test.ps1
```

## Часто задаваемые вопросы
### Q1: Мышь совсем не двигается?
Ответ: Проверяйте по пунктам:
1. Вы работаете внутри виртуальной машины / сеанса удалённого рабочего стола, который перехватывает `SetCursorPos`;
2. Программа безопасности блокирует вызовы скриптом API мыши Windows;
3. Запустите отладочный скрипт `run_test.bat`, проверьте `mouse_log.txt` чтобы убедиться, что скрипт выполняется.

### Q2: Монитор всё равно выключается при работающем скрипте?
Ответ: `SetThreadExecutionState` действует только для текущего процесса скрипта; после закрытия скрипта системные параметры питания восстанавливаются. Некоторые сторонние программы управления питанием могут переопределить эффект этого API.

### Q3: Не удаётся найти файл mouse_log.txt?
Ответ: Лог‑файл **генерируется только отладочным скриптом run_test.ps1**, релизный основной скрипт логи не создаёт.

### Q4: Со временем положение мыши постепенно смещается?
Ответ: Скрипт использует относительное смещение без фиксации начальной точки. Не перемещайте мышь вручную во время работы скрипта.

## Технические детали
1. Управление курсором: API `SetCursorPos`, `GetCursorPos` из библиотеки user32.dll
2. Реализация защиты от сна: `SetThreadExecutionState` из библиотеки kernel32.dll
    - Флаги: `ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_DISPLAY_REQUIRED`
    - Эффект: блокирует переход системы в сон и автоматическое выключение монитора; автоматически перестаёт действовать после завершения процесса.
